Круг і Прямокутник

Завершуючи розділ про прямокутники, поєднаймо дві різні геометрії! Нехай у нас є круг із центром (cx, cy) і радіусом radius та прямокутник із лівим верхнім кутом (rx, ry), шириною rw і висотою rh. Як дізнатися, чи вони перетинаються?

Секрет цього елегантного алгоритму полягає у двох кроках:

  1. Знайти на прямокутнику найближчу до центра круга точку (testX, testY).
  2. Перевірити за теоремою Піфагора, чи потрапляє ця найближча точка всередину круга (тобто чи відстань до неї не перевищує radius).

Як знайти цю найближчу точку? Почнімо з того, що створимо змінні testX і testY та спочатку прирівняємо їх до координат самого центра круга: 

let testX = cx;
let testY = cy;

Тепер «притиснемо» (обмежимо) ці координати межами прямокутника, окремо за горизонталлю і за вертикаллю: 

- Якщо центр круга ЛІВІШЕ  від прямокутника (cx < rx),    притискаємо testX до ЛІВОГО краю.
- Якщо центр круга ПРАВІШЕ від прямокутника (cx > rx+rw), притискаємо testX до ПРАВОГО краю.
  (А якщо центр круга вже між лівим і правим краями, testX залишається рівним cx!)

- Якщо центр круга ВИЩЕ    від прямокутника (cy < ry),    притискаємо testY до ВЕРХНЬОГО краю.
- Якщо центр круга НИЖЧЕ   від прямокутника (cy > ry+rh), притискаємо testY до НИЖНЬОГО краю.
  (А якщо центр круга вже між верхнім і нижнім краями, testY залишається рівним cy!)

У коді ці перевірки записуються дуже лаконічно: 

// знаходимо найближчу координату за віссю x
if (cx < rx) {
  testX = rx;            // лівий край
} else if (cx > rx + rw) {
  testX = rx + rw;       // правий край
}

// знаходимо найближчу координату за віссю y
if (cy < ry) {
  testY = ry;            // верхній край
} else if (cy > ry + rh) {
  testY = ry + rh;       // нижній край
}

Щоб краще зрозуміти логіку і суть того, що тут відбувається, візьміть аркуш паперу та самостійно зобразіть як будуть поводити себе координати при різних положеннях круга відносно квадрата. По суті, нам спочатку потрібно зрозуміти з якого боку від прямокутника знаходиться круг. Це своєю чергою допоможе визначити точку найближчої сторони прямокутника або одну з його внутрішніх точок.

Тож чому це працює? Уявіть простір навколо прямокутника:

  • Якщо круг підлітає збоку (наприклад, ліворуч, але на рівні середини вертикальної стінки), то значення testX стане рівним rx (тобто положенню лівої сторони прямокутника), а testY залишиться рівним cy. Точка (testX, testY) ковзатиме ближньою вертикальною стінкою прямо навпроти круга!
  • Якщо круг підлітає з кута (наприклад, ліворуч і вище), спрацюють обидві умови: testX стане rx, а testY стане ry. Найближчою точкою виявиться сам кут прямокутника!
  • Якщо ж центр круга вже всередині прямокутника, жодна з умов не спрацює, тому (testX, testY) залишиться рівним (cx, cy), а відстань між ними дорівнюватиме нулю.

Коли найближчу точку (testX, testY) знайдено, завдання зводиться до вже знайомого нам алгоритму «Точка і Круг»! Обчислюємо відстань від центра круга до точки (testX, testY) за теоремою Піфагора: 

const distX = cx - testX;
const distY = cy - testY;
const distance = sqrt((distX * distX) + (distY * distY));

Нарешті, порівнюємо цю відстань із радіусом круга: 

if (distance <= radius) {
  return true;
}

return false;

Ось повний код прикладу:

// координати та радіус рухомого круга
let cx = 0;
let cy = 0;
const radius = 30;

// координати та розміри прямокутника
let rx;
let ry;
const rw = 200;
const rh = 200;

function setup() {
  createCanvas(window.innerWidth, window.innerHeight);
  noStroke();

  // центруємо прямокутник на полотні
  rx = (width - rw) / 2;
  ry = (height - rh) / 2;
}

function draw() {
  background(255);

  // оновлюємо координати круга положенням курсора
  cx = mouseX;
  cy = mouseY;

  // перевіряємо зіткнення круга з прямокутником
  const isColliding = collideCircleRect(cx, cy, radius, rx, ry, rw, rh);

  // змінюємо колір прямокутника при зіткненні
  if (isColliding) {
    fill(255, 150, 0);
  } else {
    fill(0, 150, 255);
  }

  // малюємо прямокутник
  rect(rx, ry, rw, rh);

  // малюємо круг
  fill(0, 150);
  cirlce(cx, cy, radius * 2);
}

// перевірка на зіткнення між кругом і прямокутником
function collideCircleRect(cx, cy, radius, rx, ry, rw, rh) {
  // координати найближчої до круга точки прямокутника
  let testX = cx;
  let testY = cy;

  // визначаємо, який край прямокутника найближчий за віссю x
  if (cx < rx) {
    testX = rx;          // лівий край
  } else if (cx > rx + rw) {
    testX = rx + rw;     // правий край
  }

  // визначаємо, який край прямокутника найближчий за віссю y
  if (cy < ry) {
    testY = ry;          // верхній край
  } else if (cy > ry + rh) {
    testY = ry + rh;     // нижній край
  }

  // обчислюємо відстань від центра круга до знайденої точки
  const distX = cx - testX;
  const distY = cy - testY;
  const distance = sqrt((distX * distX) + (distY * distY));

  // якщо відстань не перевищує радіус — об’єкти стикаються!
  if (distance <= radius) {
    return true;
  }

  return false;
}

За ідею цього алгоритму дякуємо посібнику Мета Вордена (Matt Worden)!

До речі, якщо у вашому проєкті вже є функція collidePointCircle() із першого розділу, ви можете передати знайдену точку (testX, testY) прямо в неї, не дублюючи формулу Піфагора: 

// компактний варіант із повторним використанням collidePointCircle()
function collideCircleRect(cx, cy, radius, rx, ry, rw, rh) {
  let testX = cx;
  let testY = cy;

  if (cx < rx) {
    testX = rx;
  } else if (cx > rx + rw) {
    testX = rx + rw;
  }

  if (cy < ry) {
    testY = ry;
  } else if (cy > ry + rh) {
    testY = ry + rh;
  }

  return collidePointCircle(testX, testY, cx, cy, radius);
}

Щоб наочно побачити, як поводиться точка (testX, testY), погляньте на інтерактивну демонстрацію нижче. Помаранчева точка показує місце на межі (або всередині) прямокутника, яке в цю мить є найближчим до центра круга. Вона ніби намагається дотягнутися до курсора, але ніколи не покидає меж прямокутника!
