Лінія і Лінія

Опанувавши цей алгоритм, ви зможете створити захопливу гру про фехтування на мечах (або довести до ладу ту, яка свого часу так і не побачила світ)! Крім того, перетин двох відрізків стане нашим головним інструментом для роботи зі складними багатокутниками в наступних розділах.

Нехай перший відрізок проходить від точки (x1, y1) до (x2, y2), а другий — від (x3, y3) до (x4, y4). Щоб перевірити, чи вони перетинаються, обчислюємо два параметри — uA та uB: 

const uA = ((x4-x3) * (y1-y3) - (y4-y3) * (x1-x3)) / ((y4-y3) * (x2-x1) - (x4-x3) * (y2-y1));

const uB = ((x2-x1) * (y1-y3) - (y2-y1) * (x1-x3)) / ((y4-y3) * (x2-x1) - (x4-x3) * (y2-y1));

Що означають числа uA та uB?

На перший погляд ці дроби виглядають громіздко, проте за ними стоїть проста й красива ідея (схожа на змінну dot із попереднього розділу). Уявіть, що ви йдете вздовж першого відрізка від його початку (x1, y1) до кінця (x2, y2). Тоді число uA показує, на якій частці першого відрізка лежить точка перетину з другою прямою. А число uB показує, на якій частці другого відрізка лежить ця сама точка перетину!

  • Якщо uA = 0.5 і uB = 0.5 — два відрізки перетинаються рівно посередині кожного з них (як знак «плюс»).
  • Якщо, наприклад, uA = 1.5 — це означає, що прямі перетнулися б лише тоді, якби ми продовжили перший відрізок ще на половину його довжини вперед.

Отже, два відрізки справді перетинаються лише тоді, коли точка перетину лежить у межах обох відрізків одночасно — тобто коли і uA, і uB перебувають у діапазоні від 0 до 1: 

if (uA >= 0 && uA <= 1 && uB >= 0 && uB <= 1) {
  return true;
}

return false;

Приємний бонус цього методу: знаючи частку uA, ми можемо миттєво знайти точні координати точки перетину (intersectionX, intersectionY)! Це незамінна річ, якщо ви хочете намалювати сноп іскор саме в місці удару двох мечів або слід від лазерного променя на стіні: 

const intersectionX = x1 + (uA * (x2 - x1));
const intersectionY = y1 + (uA * (y2 - y1));

Повний код інтерактивного прикладу:

// координати першого відрізка (з рухомим кінцем)
let x1 = 0;
let y1 = 0;
const x2 = 20;
const y2 = 20;

// координати другого (статичного) відрізка
const x3 = 100;
const y3 = 300;
const x4 = 500;
const y4 = 100;

function setup() {
  createCanvas(window.innerWidth, window.innerHeight);
  strokeWeight(15); // збільшена товщина для кращої видимості ліній
}

function draw() {
  background(255);

  // оновлюємо один кінець першого відрізка координатами курсора
  x1 = mouseX;
  y1 = mouseY;

  // перевіряємо перетин двох відрізків
  const isColliding = collideLineLine(x1, y1, x2, y2, x3, y3, x4, y4);

  // змінюємо колір статичного відрізка при перетині
  if (isColliding) {
    stroke(255, 150, 0, 150);
  } else {
    stroke(0, 150, 255, 150);
  }

  // малюємо статичний відрізок
  line(x3, y3, x4, y4);

  // малюємо рухомий відрізок
  stroke(0, 150);
  line(x1, y1, x2, y2);
}

// перевірка на перетин між двома відрізками
function collideLineLine(x1, y1, x2, y2, x3, y3, x4, y4) {
  // обчислюємо параметричне положення точки перетину на обох відрізках
  const uA = ((x4 - x3) * (y1 - y3) - (y4 - y3) * (x1 - x3)) / ((y4 - y3) * (x2 - x1) - (x4 - x3) * (y2 - y1));
  const uB = ((x2 - x1) * (y1 - y3) - (y2 - y1) * (x1 - x3)) / ((y4 - y3) * (x2 - x1) - (x4 - x3) * (y2 - y1));

  // якщо uA та uB лежать у межах від 0 до 1 — відрізки перетинаються
  if (uA >= 0 && uA <= 1 && uB >= 0 && uB <= 1) {
    // необов’язково: малюємо червоний маркер у точці перетину
    const intersectionX = x1 + (uA * (x2 - x1));
    const intersectionY = y1 + (uA * (y2 - y1));
    fill(255, 0, 0);
    noStroke();
    ellipse(intersectionX, intersectionY, 20, 20);

    return true;
  }

  return false;
}

Що таке «вироджені випадки» (degenerate cases)?
У геометрії та програмуванні виродженими називають граничні випадки, коли фігури розташовуються настільки специфічно, що звичайна формула стикається з математичною невизначеністю:

1. Паралельні лінії: вони ніколи не перетинаються, тому спільний знаменник (y4 - y3) * (x2 - x1) - (x4 - x3) * (y2 - y1) дорівнює 0. У JavaScript ділення на нуль повертає спеціальне значення Infinity (нескінченність), яке не потрапляє в діапазон від 0 до 1, тож функція коректно поверне false.
2. Накладання на одній прямій (колінеарність): якщо два відрізки лежать на одній прямій і накладаються один на одного, то і чисельник, і знаменник стають рівними 0, а результат 0 / 0 дає NaN (Not-a-Number).
3. Виродження відрізка в точку: коли початок і кінець відрізка збігаються (x1 === x2 та y1 === y2), його довжина стає нульовою.

Для більшості ігор базової формули цілком достатньо, але якщо ви будуєте креслярський редактор, де лінії часто накладаються вздовж сітки, варто перевіряти знаменник на рівність нулю окремо.

Цей розділ базується на матеріалі Пола Бурка (Paul Bourke), який також містить код для перевірки паралельності ліній і вироджених випадків. А також на основі публікації Ibackstrom та обговорення на Reddit.
