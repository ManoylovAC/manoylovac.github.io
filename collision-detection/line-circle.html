Лінія і Круг

Як перевірити, чи круг зачепив відрізок? Тут ми вперше застосуємо прийом, який стане нашою суперсилою в наступних розділах: ми збудуємо новий алгоритм, поєднавши функції, які вже написали раніше!

Ідея дуже схожа на розділ «Круг і Прямокутник»: нам потрібно знайти на відрізку точку, найближчу до центра круга, а потім перевірити, чи відстань до неї не перевищує радіус круга. Розбиймо це завдання на прості кроки.

Крок 1. Перевірка кінців відрізка

Найперше перевірмо, чи хоча б один із двох кінців відрізка вже опинився всередині круга. Це трапляється, коли круг наїжджає на край лінії або коли відрізок коротший за сам круг. Для цього викличемо нашу готову функцію collidePointCircle() із розділу «Точка і Круг»: 

const inside1 = collidePointCircle(x1, y1, cx, cy, radius);
const inside2 = collidePointCircle(x2, y2, cx, cy, radius);

if (inside1 || inside2) {
  return true;
}

Крок 2. Пошук найближчої точки на прямій (проєкція)

Якщо обидва кінці відрізка лежать поза кругом, круг все одно може перетинати його десь посередині! Щоб знайти найближчу точку на прямій до центра круга, уявіть, що з центра круга перпендикулярно (під прямим кутом 90°) на лінію падає промінь. Місце, куди він влучить, називається ортогональною проєкцією точки на пряму.

Спочатку обчислимо довжину нашого відрізка lineLen за теоремою Піфагора: 

const distX = x1 - x2;
const distY = y1 - y2;
const lineLen = sqrt((distX * distX) + (distY * distY));

Далі скористаємося формулою з векторної геометрії — скалярним добутком (dot product), поділеним на квадрат довжини відрізка: 

const dot = (((cx - x1) * (x2 - x1)) + ((cy - y1) * (y2 - y1))) / pow(lineLen, 2);

Якщо ви ще не вивчали векторну алгебру, не лякайтеся цієї формули! Її результат dot має дуже простий інтуїтивний зміст: це частка шляху вздовж відрізка від його початку (x1, y1) до його кінця (x2, y2), де падає перпендикуляр від центра круга:

  • Якщо dot = 0 — найближча точка збігається з початком відрізка (x1, y1).
  • Якщо dot = 0.5 — найближча точка лежить рівно посередині відрізка.
  • Якщо dot = 1 — вона збігається з кінцем відрізка (x2, y2).

Маючи число dot, ми легко обчислюємо координати цієї найближчої точки (closestX, closestY), відступивши від початку лінії на частку dot: 

const closestX = x1 + (dot * (x2 - x1));
const closestY = y1 + (dot * (y2 - y1));

Примітка для допитливих: більше про природу векторів та скалярного добутку можна прочитати українською в книзі Деніела Шиффмана «Природа коду» — у розділах про вектори та автономних агентів.

Крок 3. Чи лежить точка в межах відрізка?

Формула проєкції шукає найближчу точку на нескінченній прямій. Якщо круг відійшов далеко вбік за межі кінців відрізка, точка (closestX, closestY) опиниться на уявному продовженні лінії в порожнечі!

Тож перевірмо, чи справді знайдена точка лежить на нашому відрізку, викликавши функцію collideLinePoint() із попереднього розділу «Лінія і Точка»: 

const isOnSegment = collideLinePoint(x1, y1, x2, y2, closestX, closestY);

if (!isOnSegment) {
  return false;
}

Крок 4. Перевірка відстані до радіуса

Якщо точка лежить на відрізку, залишається знайти відстань від неї до центра круга і порівняти з радіусом: 

const distX = closestX - cx;
const distY = closestY - cy;
const distance = sqrt((distX * distX) + (distY * distY));

Якщо ця відстань менша за радіус круга (або дорівнює йому), ми маємо зіткнення! (Так само як Точка і Круг). 

if (distance <= radius) {
  return true;
}

return false;

Ось повний код прикладу, який об’єднує всі три функції. Зверніть увагу на червону крапку, що бігає вздовж лінії, — це і є наша проєкція (closestX, closestY)! 

// координати та радіус рухомого круга
let cx = 0;
let cy = 0;
const radius = 30;

// координати кінців відрізка
let x1;
let y1;
let x2;
let y2;

function setup() {
  createCanvas(window.innerWidth, window.innerHeight);
  strokeWeight(15); // збільшена товщина для кращої видимості лінії

  x1 = 100;
  y1 = height - 100;
  x2 = width - 100;
  y2 = 100;
}

function draw() {
  background(255);

  // оновлюємо положення круга координатами курсора
  cx = mouseX;
  cy = mouseY;

  // перевіряємо зіткнення лінії та круга
  const isColliding = collideLineCircle(x1, y1, x2, y2, cx, cy, radius);

  // змінюємо колір лінії при зіткненні
  if (isColliding) {
    stroke(255, 150, 0, 150);
  } else {
    stroke(0, 150, 255, 150);
  }

  // малюємо лінію
  line(x1, y1, x2, y2);

  // малюємо круг
  fill(0, 150);
  noStroke();
  ellipse(cx, cy, radius * 2, radius * 2);
}

// перевірка на зіткнення між лінією та кругом
function collideLineCircle(x1, y1, x2, y2, cx, cy, radius) {
  // чи лежить хоча б один кінець відрізка всередині круга?
  const inside1 = collidePointCircle(x1, y1, cx, cy, radius);
  const inside2 = collidePointCircle(x2, y2, cx, cy, radius);
  if (inside1 || inside2) {
    return true;
  }

  // обчислюємо довжину відрізка
  let distX = x1 - x2;
  let distY = y1 - y2;
  const lineLen = sqrt((distX * distX) + (distY * distY));

  // знаходимо нормалізований скалярний добуток (проєкцію)
  const dot = (((cx - x1) * (x2 - x1)) + ((cy - y1) * (y2 - y1))) / pow(lineLen, 2);

  // обчислюємо координати найближчої точки на прямій
  const closestX = x1 + (dot * (x2 - x1));
  const closestY = y1 + (dot * (y2 - y1));

  // перевіряємо, чи лежить ця точка в межах самого відрізка
  const isOnSegment = collideLinePoint(x1, y1, x2, y2, closestX, closestY);
  if (!isOnSegment) {
    return false;
  }

  // необов’язково: малюємо червоний маркер у найближчій точці на відрізку
  fill(255, 0, 0);
  noStroke();
  ellipse(closestX, closestY, 20, 20);

  // обчислюємо відстань від центра круга до найближчої точки відрізка
  distX = closestX - cx;
  distY = closestY - cy;
  const distance = sqrt((distX * distX) + (distY * distY));

  if (distance <= radius) {
    return true;
  }

  return false;
}

// перевірка на зіткнення між лінією та точкою
function collideLinePoint(x1, y1, x2, y2, px, py) {
  const d1 = dist(px, py, x1, y1);
  const d2 = dist(px, py, x2, y2);
  const lineLen = dist(x1, y1, x2, y2);
  const buffer = 0.1;

  if (d1 + d2 >= lineLen - buffer && d1 + d2 <= lineLen + buffer) {
    return true;
  }

  return false;
}

// перевірка на зіткнення між точкою та кругом
function collidePointCircle(px, py, cx, cy, radius) {
  const distX = px - cx;
  const distY = py - cy;
  const distance = sqrt((distX * distX) + (distY * distY));

  if (distance <= radius) {
    return true;
  }

  return false;
}

Реалізацію багатьох геометричних операцій під час роботи з лініями та фігурами можна спростити завдяки методам класу p5.Vector. Якщо ви раніше не користувалися векторами, радимо з ними ознайомитися. У книзі Деніела Шиффмана «Природа коду» (The Nature of Code) є розділ, присвячений векторам. Ми також детальніше торкнемося p5.Vector, коли почнемо працювати з багатокутниками.
