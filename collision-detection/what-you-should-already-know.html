Що бажано знати

Усі приклади в цій книзі написані з використанням бібліотеки p5.js для мови JavaScript (в оригінальній книзі це Processing — середовище на базі мови Java). Щоб комфортно працювати з матеріалом, вам не потрібно бути досвідченим розробником. Достатньо розуміти базову будову скетчу в p5.js, уміти створювати змінні, малювати прості фігури, зчитувати координати курсора миші (mouseX, mouseY) і користуватися умовними конструкціями if / else.

У розділах про багатокутники нам також стане в пригоді клас p5.Vector для зручного зберігання точок із координатами x та y, але ми обов’язково розберемо основи роботи з ним, коли дійдемо до відповідної теми.

Наприкінці посібника ми розглянемо, як організувати перевірку зіткнень в об’єктно-орієнтованому стилі за допомогою класів. Знати об’єктно-орієнтоване програмування наперед необов’язково, проте цей розділ покаже, як зручно керувати десятками рухомих об’єктів у справжній грі.

Раніше не працювали з p5.js? Не біда! Якщо ви знайомі з будь-якою іншою мовою програмування, логіка алгоритмів буде для вас цілком прозорою, і ви легко перенесете цей код у свій улюблений рушій чи середовище.

Система координат полотна

Перш ніж перейти до формул, важливо пригадати одну особливість комп’ютерної графіки. На відміну від шкільних уроків геометрії, де початок координат розташований у центрі, а вісь y спрямована вгору, на цифровому полотні початок відліку (0, 0) знаходиться у лівому верхньому куті:

  • Координата x зростає праворуч (від 0 до ширини полотна width).
  • Координата y зростає донизу (від 0 на верхньому краї до висоти полотна height унизу).

Тримайте цю картинку в уяві: коли ми кажемо, що одна точка розташована нижче за іншу, її координата y насправді більша, а коли вище — її координата y менша.

Функції

Серцем кожного прикладу в цій книзі є функції. Якщо ви ще не створювали власних функцій, уважно прочитайте цей короткий огляд. Якщо ж ви впевнено ними користуєтеся, можете одразу переходити далі.

Функція — це самодостатній блок коду, якому ми даємо ім’я, щоб викликати його скільки завгодно разів у різних місцях програми. Саме так зручно оформлювати перевірку зіткнення між двома фігурами.

Виконавши роботу, функція зазвичай повертає результат певного типу (наприклад, число або логічне значення true чи false) за допомогою ключового слова return. Ось проста функція, яка повертає текстовий рядок «Привіт!»: 

function sayHi() {
  return 'Привіт!';
}

Інколи функції не потрібно нічого повертати — наприклад, коли вона просто малює фігуру на екрані. Тоді інструкція return не обов’язкова (у такому разі функція типово поверне undefined). Звучить знайомо? Основні блоки будь-якої програми на p5.js — setup() та draw() — це теж функції!

Щоб функція могла працювати з різними вхідними даними, їй передають параметри (або аргументи). Кожному параметру в круглих дужках задається ім’я, яким ми користуємося всередині функції. Ось функція, яка приймає два числа і повертає їхню суму: 

function sum(a, b) {
  return a + b;
}

Викликати нашу функцію sum() і зберегти її результат у змінну можна так: 

const result = sum(2, 2);
console.log(result); // виведе 4

Усі алгоритми виявлення зіткнень у цьому посібнику оформлені як функції виду collide<Фігура1><Фігура2>(). Ми передаємо їм координати й розміри двох об’єктів, а у відповідь отримуємо булеве значення: true (зіткнення відбулося) або false (об’єкти не торкаються).

Як ми називаємо змінні в цій книзі

У реальному коді або математичних бібліотеках програмісти часто використовують дуже короткі однобуквені імена змінних, щоб формули займали менше місця. Натомість у великих прикладних програмах прийнято давати максимально повні описові назви.

Для навчальних цілей цієї книги ми обрали золоту середину — помірно розгорнуті назви:

  • Координати й розміри фігур, які постійно повторюються у математичних формулах, мають лаконічні префікси за назвою фігури: px, py для точки (point), cx, cy, radius для круга (circle), rx, ry, rw, rh для прямокутника (rectangle — координати, ширина та висота), x1, y1, x2, y2 для кінців відрізка. Завдяки цьому формули не розтягуються на кілька рядків і легко читаються.
  • Натомість усі змінні, що відповідають за логіку алгоритму чи проміжні обчислення, мають зрозумілі самопояснювальні імена: isColliding, currentVertex, nextVertex, closestX, lineLen тощо.

Дійсні числа в JavaScript

Якщо ви зазирнете в англомовний оригінал книги, написаний для Processing (Java), то побачите там окремий розділ про різницю між цілими числами (int) та дробовими числами з рухомою крапкою (float), адже в Java ділення двох цілих чисел відкидає дробову частину.

У JavaScript та p5.js усі числа типово є числами з рухомою крапкою подвійної точності, тому проблема цілочислового ділення вам не загрожує. Проте робота з дробовими числами в комп’ютері має інший цікавий нюанс — крихітні похибки округлення під час складних обчислень. Ми обов’язково покажемо, як легко з ними впоратися, коли дійдемо до розділу «Лінія і Точка».
